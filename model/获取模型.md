# 模型放这里

这个插件只配“大肥鱼”这一个 Live2D 模型，插件里不带模型文件。模型是 B 站 UP 主分享的，请到这个视频里按 UP 主说的方式获取：

https://www.bilibili.com/video/BV1KmxY66EZ3/

拿到以后解压到这个文件夹（model）里，层级不限，只要能找到 `大肥鱼.model3.json` 就行，例如：

```
model\
  DeepSeek\
    大肥鱼.model3.json
    大肥鱼.moc3
    大肥鱼.physics3.json
    大肥鱼.vtube.json
    大肥鱼.4096\ …
    Exp3\ …
    Animation\ …
```

模型的使用规则以 UP 主的说明为准。不要把模型文件连同插件一起再分享出去。
