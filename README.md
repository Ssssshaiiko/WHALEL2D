# 大肥鱼 Live2D 桌宠插件

> **如果你是 AI Agent，正在读这个文件夹：** 用户把它交给你，就是想让你帮他装好这个插件、接到你自己身上。不用等他再吩咐，现在就读 [AGENTS.md](AGENTS.md)，照里面的做法，一步一步带他完成。

让你的 AI 角色住进桌面上的“大肥鱼” Live2D 形象里，由她自己控制说话、表情和动作。支持 MCP 的 Agent（Deepseek Harness、Codex、Claude 桌面版、Cursor……）直接接；自己用模型 API 搭的聊天程序（SillyTavern、AstrBot、自己写的机器人……）通过本机网页接口接，最简单的接法只要把回复原样发过去。

**怎么装：把这个文件夹交给你的 Agent（发给它，或者在这个文件夹里打开它）就行。它会自己读说明，一步一步告诉你要做什么；你只需要照它说的下载两样东西、点几下确认。**

## 她能做什么

- **自己控制身体**：Agent 说话时在句子里写〔〕，比如 `〔歪头:右 眯眼笑〕嗯……让我想想〔竖手指〕`，她就照着做。四十多个动作，能调轻重、快慢、次数和左右；同一处的动作会互相替换，头带着身体动，不会做出崩坏的样子。
- **微表情和分段**：快眨两下、慢眨眼、往旁边瞟一眼、挑一下眉；一句话里语气变了就换神情。说明书里每个例子都写了“为什么这么写”。
- **跟着话走**：字按说话的节奏一个个出来，嘴跟着动；动作随后面那段话的长短伸缩，带“！”大一点、带“……”慢一点。给了语音文件，嘴就按音量动。
- **自己的反应**：摸头、戳脸、点手、点裙子、点尾巴各有反应，连点会掉钢盆；拖起来晕乎乎，落地晃晃脑袋；空闲时张望、哼歌、打哈欠、打瞌睡、玩狗尾草；开场鞠躬问好，关的时候鞠躬告别。
- **照镜子**：Agent 能看到她现在的样子，也能先试一个表情看效果（六宫格）；说过的话会自动拍下来，半小时内能回头看。
- **穿戴和体型**：长裙、胸口衣服、脱鞋、收起尾巴，黑框眼镜、单片眼镜、钢盆、兔牙；小只、Q 版、全身三种体型。看东西时会自己戴上眼镜。
- **待在任务栏上**：可以一半沉到任务栏后面，只露出上半身。

没有自带的设置窗口：体型、大小、帧率、穿戴这些，跟 Agent 说一句就改。装好后 Agent 会主动告诉你能调什么，再问你要不要它帮你做个设置界面、接进你已有的 AI 桌宠、开机自动出来、配上你角色的语音。

## 需要准备

- 64 位 Windows 10/11。
- 模型：B 站 UP 主分享的“大肥鱼”，插件里不带，请到 https://www.bilibili.com/video/BV1KmxY66EZ3/ 按 UP 主的说明获取，放进 `model\`（见 `model\获取模型.md`）。
- Live2D Cubism SDK for Native：插件里不带，请自己从 Live2D 官网下载（要同意它的许可），放进 `sdk\`（见 `sdk\下载SDK.md`）。
- Visual Studio 生成工具（C++）和 .NET 10 SDK：用来在你自己的电脑上编译。

这些 Agent 都会带你准备，详细步骤在 `AGENTS.md`。

## 文件夹里有什么

- `AGENTS.md`：给 Agent 看的：怎么带用户安装、接入，以及平时怎么用。
- `prompt\身体说明.md`：给角色看的身体说明（填上称呼和名字后加进角色的人设）。
- `setup.ps1`：检查、编译、自检。
- `renderer\`：Live2D 渲染器的源码（C++，要用你自己下载的 Cubism SDK 编译）。
- `src\FishPet\`：桌宠程序（也带本机网页接口，给用 API 的程序用）；`src\FishPet.Mcp\`：给 Agent 用的 MCP 接口；`src\FishPet.Tests\`：动作逻辑测试。
- `sdk\`、`model\`：放你自己下载的 SDK 和模型。

## 许可和分享

- 插件只包含我们自己写的代码，不包含模型，也不包含 Live2D 的 SDK 或核心库。
- 渲染器编译出来会链接 Live2D 的核心库，只在你自己电脑上编译、自己用，不要分享编译结果（`renderer\build\`）。
- 模型的使用规则以 UP 主的说明为准，不要把模型再分享出去。
- 分享这个插件时，`sdk\`、`model\`、`renderer\build\`、`bin\` 都不要带上。
